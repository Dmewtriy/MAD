# ЛР 1.3 – дополнительное задание

Итоговый документ – **Отчёт_ЛР1.3_Дополнительное_задание.docx**.
Текст с теми же таблицами и выводами – **REPORT.md**.

Два новых для текущего основного отчёта метода:

- ANOVA Уэлча;
- ANOVA Брауна–Форсайта с поправкой Мехротры к степеням свободы.

Оба метода сравнивают **средние цены** по трём типам привода при неодинаковых
дисперсиях. ANOVA Брауна–Форсайта здесь является проверкой средних;
проверка равенства дисперсий выполняется отдельно критерием Левена с центром
в медиане. Использованы только `price` и `drive-wheels` из того же Automobile.
После исключения четырёх пропусков цены осталось 201 наблюдение.

Новые методы не требуют наддува, поэтому `aspiration` исключена из перечня
анализируемых переменных. Описательные характеристики цены и групп совпадают
с актуальным основным отчётом. Раздел 4 содержит только краткое сравнение
и интерпретацию, без дополнительных проверок и метрик.

Оформление берётся **из текущего Word-файла ЛР 1.3**, прочитанного заново.
Его копия находится в `template/Оформление_ЛР1.3.docx`, контрольная сумма –
в `template/reference.json`. Сохранены титульный лист с исполнителями,
стили заголовков, начало основных глав с новой страницы, сетка и геометрия
таблиц, шрифт таблиц 12 пт, подписи таблиц справа, рисунки шириной 16,3 см
с подписью по центру и пустой строкой после неё. Цветная заливка не добавляется.

Данные и описание признаков находятся в `data/`, таблицы расчётов и графики –
в `results/`. Исходные файлы основной ЛР 1.3 не изменяются.

Для воспроизведения из корня рабочего пространства:

```bash
lab1.3/.venv/bin/python 1.3_opt/anova_analysis.py
lab1.3/.venv/bin/python 1.3_opt/build_report.py
```

При переносе в другую среду достаточно зависимостей из `requirements.txt`.
Формулы Уэлча проверяются по statsmodels и SciPy; формулы Брауна–Форсайта
с поправкой Мехротры – по statsmodels. Выводы ограничены асимметрией цен,
малой группой 4wd и наблюдательным характером данных.
