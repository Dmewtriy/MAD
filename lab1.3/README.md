# Лабораторная работа 1.3 — дисперсионный анализ

Исследуется **цена автомобиля `price`** из того же набора Automobile, что использовался в лабораторных 1.1 и 1.2. Цена является зависимой **количественной** переменной. Фактор однофакторного анализа — тип привода `drive-wheels` (`4wd`, `fwd`, `rwd`). Второй фактор для дополнительного задания — тип наддува `aspiration` (`std`, `turbo`).

Основной файл для сдачи: [Отчёт_ЛР1.3_Дисперсионный_анализ.docx](Отчёт_ЛР1.3_Дисперсионный_анализ.docx). Титульный лист и оформление взяты из актуального отчёта 1.2; исходные отчёты не изменяются. Текст с теми же таблицами и рисунками доступен в [REPORT.md](REPORT.md).

## Результаты

Из 205 записей исключены 4 строки без цены; во всех анализах участвует одна выборка из **201 наблюдения**. Размеры групп: `4wd` — 8, `fwd` — 118, `rwd` — 75. Средние цены: 10 241,00; 9 244,78; 19 757,61 долл. соответственно.

ANOVA Фишера: F(2; 198) = 67,9541, p = 3,395e-23. ANOVA Уэлча: F(2; 19,3559) = 44,7198, p = 5,540e-08. Краскел–Уоллис: H(2) = 93,1889, p = 5,811e-21. Попарные проверки с поправкой Холма подтверждают различия `rwd` с двумя другими группами; различие `4wd` и `fwd` не подтверждено.

Распределения цены ненормальны, а дисперсии групп различаются. Поэтому в отчёте приведены ограничения классического F-теста и дополнительные проверки. Краскел–Уоллис интерпретируется как проверка распределений и рангов; при разном разбросе его нельзя считать прямой проверкой равенства только медиан или средних.

Для двухфакторного анализа использованы суммы квадратов типа III и контрасты с нулевой суммой. Привод значим и в классической модели, и при HC3; взаимодействие незначимо. Результат для наддува чувствителен к способу оценки: p = 0,28577 в классической ANOVA и p = 0,03782 при HC3. В ячейке `4wd × turbo` всего 2 наблюдения. Эти ограничения явно отражены в отчёте.

## Файлы расчётов

- `anova_analysis.py` — подготовка данных, статистические расчёты и графики.
- `build_report.py` — сборка Markdown и Word из готовых результатов.
- `results/analysis_data.csv`, `excluded_rows.csv`, `data_quality.csv` — очищенная выборка, исключённые строки и проверка качества.
- `results/descriptive_statistics.csv`, `frequencies_*.csv`, `histogram_bins.csv`, `normality_shapiro.csv`, `variance_homogeneity.csv` — дескриптивные показатели и предпосылки.
- `results/price_groups.csv` — полные числовые выборки по приводу; пустые клетки в конце столбцов обусловлены разными размерами групп.
- `results/one_way_anova.csv`, `welch_anova.csv`, `pairwise_welch_holm.csv` — анализ средних.
- `results/kruskal_wallis.csv`, `kruskal_ranks.csv`, `ranked_data.csv`, `pairwise_dunn_holm.csv` — ранговый анализ.
- `results/two_way_*.csv` — двухфакторный анализ, статистики ячеек, коэффициенты, остатки и контроль расчётов.
- `results/*.png` — шесть рисунков, встроенных в отчёт.
- `results/summary.json` — итоговые показатели, версии библиотек, SHA-256 исходных данных и результаты числовых проверок.

F Фишера, F Уэлча и H Краскела–Уоллиса рассчитаны по формулам и сверены с SciPy. Частные F двухфакторной модели независимо проверены через вложенные модели NumPy. Проверки выполняются при каждом запуске; ошибка прерывает расчёт.
