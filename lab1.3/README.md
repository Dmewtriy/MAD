## Основные результаты

Из 205 исходных записей исключены 4 строки без цены. Во всех анализах используются 201 наблюдение: `4wd` — 8, `fwd` — 118, `rwd` — 75.

Однофакторная ANOVA: F(2; 198) = 67,9541, p = 3,395e-23. η² = 0,4070. Гипотеза равенства всех средних цен отвергается.

Краскел–Уоллис: H(2) = 93,1889, p = 5,811e-21. Гипотеза одинаковых распределений цены отвергается. Эти общие проверки не устанавливают значимость каждой отдельной пары групп.

Двухфакторная модель: `price ~ C(drive) * C(aspiration)`. В расчёт сначала включается привод, затем наддув и затем взаимодействие; порядок фиксируется из-за неодинаковых размеров ячеек. Для привода p = 2,378e-23, для наддува после учёта привода p = 0,06471, для взаимодействия p = 0,33784. При α = 0,05 значим привод; два остальных эффекта не подтверждены.

## Таблицы и графики

В `results` сохранены очищенные данные с номерами исходных строк, исключённые записи, статистики качества, описательные показатели и частоты факторов. Основные файлы расчётов:

- `one_way_anova.csv` — однофакторная таблица ANOVA.
- `kruskal_ranks.csv`, `kruskal_wallis.csv`, `ranked_data.csv` — ранги и критерий Краскела–Уоллиса.
- `two_way_anova.csv`, `two_way_cell_statistics.csv`, `two_way_cell_counts.csv` — двухфакторная таблица и характеристики ячеек.
- `two_way_coefficients.csv`, `two_way_residuals.csv`, `two_way_metrics.csv` — параметры модели и остатки.
- `histogram_bins.csv`, `normality_shapiro.csv`, `price_groups.csv` — интервалы гистограмм, проверка нормальности и полные выборки по приводу.
- `summary.json` — итоговые показатели, версии библиотек, SHA-256 данных и результаты числовых сверок.
- Пять рисунков отчёта: частоты факторов, гистограммы, диаграмма размаха, Q–Q-графики и взаимодействие средних.

Однофакторные суммы квадратов и статистика H независимо вычислены по формулам и сверены с SciPy. Двухфакторная таблица проверена по последовательно вложенным моделям NumPy; суммы квадратов эффектов и остатка складываются в общую сумму квадратов.

После подписей рисунков вставлена пустая строка. Перед заголовками задан интервал в одну строку, который подавляется вверху страницы; после заголовков вставлена пустая строка.
