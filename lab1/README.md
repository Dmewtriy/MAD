# Лабораторная №1. Методы анализа данных

Итоговый Markdown-отчёт по требуемой структуре: [REPORT.md](REPORT.md).
Он включает цель работы, результаты анализа Automobile и отдельный пример
ложной корреляции с исходными данными, графиками и проверкой линейных трендов.
Нумерация разделов 2-8 сохранена по требованиям; титульный лист не добавлялся.

Сформировать итоговый отчёт и обновить расчёты из корня проекта:

```powershell
& .\lab1\venv\Scripts\python.exe .\lab1\build_report.py
```

Пункты 1-8: описание данных, дескриптивный анализ, описательная оценка
нормальности по гистограмме, гистограмма массы по Стерджессу,
частоты категорий, таблица сопряжённости, ранговая корреляция Спирмена,
оценка её значимости и интерпретация результатов.

Выбранные переменные: зависимая `symboling`, независимые `drive-wheels`
и `curb-weight`. Данные и их исходное описание находятся в `data/`.
Скрипт читает локальные данные, доступ к сети при запуске не требуется.

Запуск из корня проекта в PowerShell с существующим окружением:

```powershell
& .\lab1\venv\Scripts\python.exe .\lab1\statistical_analysis.py
```

Для нового окружения (Python 3.14, версии зависимостей из текущего окружения):

```powershell
python -m venv lab1/venv
& .\lab1\venv\Scripts\python.exe -m pip install -r lab1/requirements.txt
& .\lab1\venv\Scripts\python.exe .\lab1\statistical_analysis.py
```

Результаты сохраняются в `results/statistics/`: `report.md` с выводами,
таблицы CSV в UTF-8 с BOM, два рисунка PNG. Повторный запуск обновляет результаты.
Можно указать другие пути через `--data` и `--output`.

Для `symboling` рассчитываются частоты, процентные доли и самая частая категория.
В корреляционном анализе используется порядок её категорий. Скрипт
`statistical_analysis.py` выполняет пункты 1-8 основного анализа;
`build_report.py` дополнительно рассчитывает пример ложной корреляции и собирает
итоговый отчёт. Данные примера сохранены в `data/spurious_margarine_divorce.csv`,
ссылка на источник приведена в итоговом отчёте; повторный запуск работает без сети.
