# Конспект: кластеризация категориальных и смешанных данных

Конспект составлен по шести предоставленным презентациям. Внешние источники указаны непосредственно у дополнений. Экспериментальная часть для согласованного Bank Marketing находится в [отчёте](../Отчёт_ЛР3_Кластеризация.docx).

## 1. Методы кластеризации категориальных и смешанных данных

Кластеризация ищет группы похожих объектов без использования целевой переменной при построении разбиения. Если в наборе есть известный класс, его можно сохранить отдельно для последующей внешней оценки. Кластеры не обязаны воспроизводить этот класс: признаки могут отражать несколько разных структур.

Номинальные признаки задают категории без арифметического смысла: например, профессия или цвет. Порядковые признаки задают порядок, но не обязательно равные расстояния между уровнями. Числа, которыми закодированы категории, сами по себе не делают признак количественным.

| Данные | Подход | Представитель кластера и мера различия |
| --- | --- | --- |
| Количественные | k-means | Среднее; сумма квадратов евклидовых расстояний |
| Категориальные | k-modes | Покомпонентные моды; число несовпадений |
| Смешанные | k-prototypes | Средние для числовой части и моды для категориальной |
| Категориальные и транзакционные | CLOPE | Частоты элементов; глобальный критерий Profit |
| Категориальные и смешанные | k-medoids | Реальный объект-медоид; например, расстояние Гауэра |
| Категориальные и смешанные | Иерархическая кластеризация | Матрица расстояний; average или complete linkage |
| Данные с подходящей мерой близости | DBSCAN | Плотность в ε-окрестностях; отдельная метка шума |

В k-medoids медоид минимизирует сумму расстояний до объектов своего кластера. В иерархическом методе single linkage использует минимальное межобъектное расстояние между кластерами, complete — максимальное, average — среднее всех межкластерных пар. Single linkage склонен образовывать цепочки. Метод Уорда основан на приросте суммы квадратов в евклидовом пространстве; произвольную матрицу Гауэра нельзя автоматически считать подходящим входом для него.

В DBSCAN корневой объект имеет не менее `min_samples` объектов в своей ε-окрестности, включая себя в реализации scikit-learn. Пограничный объект находится рядом с корневым, но не удовлетворяет условию плотности; остальные объекты могут стать шумом. Разная плотность групп затрудняет выбор единого ε.

Обычный k-means не позволяет просто заменить евклидово расстояние на Гауэра: обновление среднего связано с его целевой функцией. Для готовой матрицы Гауэра подходят, например, k-medoids и иерархический метод со средней связью. Для категориальных признаков k-modes является самостоятельной допустимой альтернативой в рамках задания.

## 2. Алгоритм k-prototypes

Источник в предоставленной теории: «Кластеризация.Категор.Смешанн.Данных.pdf», страницы 6–14.

Пусть `N` — множество числовых признаков, `C` — категориальных. Различие объекта `x` и прототипа `μ`:

```text
d(x, μ) = Σ[j ∈ N] (x_j − μ_j)² + γ · Σ[j ∈ C] I(x_j ≠ μ_j).
```

Индикатор `I` равен 1 при выполнении условия и 0 в остальных случаях. Алгоритм минимизирует сумму таких различий по объектам и назначенным им кластерам.

1. Задать число кластеров `k`, параметр `γ` и начальные прототипы.
2. Назначить каждый объект ближайшему прототипу.
3. Пересчитать числовые координаты прототипа как средние, категориальные — как моды.
4. Повторять назначения и обновления до остановки.

`γ` управляет весом всей категориальной части относительно числовой. Большое значение усиливает влияние несовпадающих категорий. Масштабы числовых признаков и число признаков в каждой части влияют на баланс. Поэтому числовую подготовку и выбор `γ` нужно обосновать; разные значения целевой функции при разных `γ` напрямую не сравниваются.

Результат зависит от инициализации. Следует использовать несколько запусков и фиксировать генератор случайных чисел. Готовая реализация — `kmodes.kprototypes.KPrototypes`; категориальные столбцы задаются явно. [Исходный код и параметры реализации](https://github.com/nicodv/kmodes/blob/master/kmodes/kprototypes.py).

## 3. Алгоритм k-modes

Для объекта и центра кластера используют различие:

```text
d_match(x, μ) = Σ[j = 1..p] I(x_j ≠ μ_j).
J = Σ[кластеры c] Σ[x ∈ c] d_match(x, μ_c) → min.
```

Центр — вектор наиболее частых категорий по каждому признаку. Он может не совпадать с какой-либо строкой исходного набора. При равенстве частот правило выбора моды зависит от реализации.

Алгоритм задаёт начальные моды, чередует назначение объектов ближайшей моде и пересчёт мод, затем останавливается при стабилизации или достижении ограничения итераций. Требуется заранее выбрать `k`. Возможны локальные минимумы, поэтому полезны несколько инициализаций. Число кластеров выбирают по внутренним метрикам, устойчивости и содержательности профилей.

В Python используется `kmodes.kmodes.KModes`. Библиотека предоставляет инициализации Huang и Cao, параметр `n_init`, итоговые метки, моды и стоимость. Пропуски нужно предварительно обработать. [Документация библиотеки kmodes](https://github.com/nicodv/kmodes).

## 4. Алгоритм CLOPE

Источник в предоставленной теории: «Кластеризация.Категор.Смешанн.Данных.pdf», страницы 15–24.

### Представление данных

Каждую строку превращают в транзакцию из элементов вида `имя_признака=значение`:

```text
{job=technician, marital=married, housing=yes}
```

Имя признака обязательно входит в элемент: `housing=yes` и `loan=yes` обозначают разные свойства. Идентификатор строки нужен для соединения результатов и не включается в транзакцию как признак. Известный класс тоже хранится отдельно.

Непрерывные признаки для CLOPE можно предварительно разбить на интервалы. Границы и способ разбиения сохраняют. Для корректного сравнения двух методов необходимо явно описать, используют ли они одинаковое представление данных.

### Характеристики кластера и целевая функция

Для кластера `c`:

- `N(c)` — число транзакций;
- `Occ(a,c)` — число вхождений элемента `a`;
- `S(c) = Σ[t ∈ c] |t|` — суммарное число элементов с повторениями между транзакциями;
- `W(c) = |⋃[t ∈ c] t|` — число различных элементов;
- `H(c) = S(c) / W(c)` — средняя высота частотной гистограммы.

Глобальный критерий:

```text
Profit(P, r) = (1/n) · Σ[c ∈ P] N(c) · S(c) / W(c)^r → max.
```

`P` — разбиение, `n` — число всех транзакций, `r > 1` — коэффициент отталкивания. При `r = 2` множитель `S/W²` равен отношению высоты гистограммы к ширине. Переиспользование одинаковых элементов внутри группы позволяет получить более узкую и высокую гистограмму.

Больший `r` сильнее штрафует разнообразие элементов внутри кластера и обычно приводит к большему числу более однородных кластеров. Это тенденция, а не гарантия строгой монотонности для конкретной эвристической реализации. Значения Profit при разных `r` нельзя напрямую ранжировать как одну шкалу качества.

### Ход алгоритма

При первом проходе очередную транзакцию помещают в существующий или новый кластер с наибольшим приростом критерия. Затем выполняют повторные проходы: транзакцию временно удаляют из текущей группы и выбирают её новое размещение. Остановка происходит, когда перемещений больше нет, либо срабатывает установленное ограничение.

Для оценки размещения достаточно счётчиков `N`, `S`, `W`, `Occ`; полная матрица попарных расстояний не требуется. Число кластеров формируется в процессе работы. Решение зависит от `r`, порядка строк и ограничений; несколько перестановок строк помогают оценить устойчивость.

У CLOPE нет обычного числового центроида. Для интерпретации сохраняют частотные профили, моды и при необходимости медоид по отдельно выбранной мере. Расстояние до такого медоида — дополнительная характеристика, а не целевая функция CLOPE.

Первоисточник: Yang Y., Guan X., You J. (2002), [CLOPE: a fast and effective clustering algorithm for transactional data](https://doi.org/10.1145/775047.775149). Дополнительное объяснение: [статья Loginom](https://loginom.ru/blog/clope).

## 5. Меры расстояния

### Хэмминг

Для категориальных векторов одинаковой длины:

```text
d_H(x,y) = Σ[j] I(x_j ≠ y_j),
d_H_normalized(x,y) = d_H(x,y) / p.
```

Первый вариант — число несовпадений, второй — их доля. Например, `(красный, круглый, большой)` и `(красный, квадратный, малый)` отличаются по двум из трёх признаков: расстояния равны 2 и 2/3 соответственно. При фиксированном `p` нормировка не меняет выбор ближайшего центра.

SciPy возвращает нормированный вариант. Категории допустимо кодировать отдельными целыми значениями внутри каждого столбца, если затем сравнивается только равенство кодов. Арифметические разности кодов использовать нельзя. [Определение SciPy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.spatial.distance.hamming.html).

### Гауэр

Общая формула — среднее различий по доступным признакам с учётом весов:

```text
d_G(x,y) = Σ[j] w_j · δ_j(x,y) · d_j(x,y)
           / Σ[j] w_j · δ_j(x,y).
```

`w_j` — вес признака; `δ_j` показывает, допустимо ли учитывать конкретное сравнение. Для номинального признака `d_j = I(x_j ≠ y_j)`. Для количественного признака `d_j = |x_j − y_j| / R_j`, где `R_j` — размах. Порядковые уровни сначала переводят в упорядоченную нормированную шкалу.

При пропуске у любого из двух объектов соответствующее сравнение исключается. Для асимметричного бинарного признака дополнительно исключается совпадение `0–0`; несовпадение `0–1` учитывается. Постоянные признаки не несут разделяющей информации, их лучше убрать. При отсутствии доступных сравнений расстояние не определено.

Для полностью номинальных данных без пропусков и с равными весами Гауэр совпадает с нормированным Хэммингом. Это следует из формулы. Если учитывать порядковые уровни через ранги, равенство в общем случае исчезает. [Подробное определение в документации daisy](https://stat.ethz.ch/R-manual/R-devel/library/cluster/html/daisy.html).

### Журавлев

Идея — засчитывать совпадение количественных характеристик с заданным допуском. Зафиксируем соглашение о включённой границе допуска:

```text
s_j(x,y) = I(|x_j − y_j| ≤ ε_j)        для числового признака,
s_j(x,y) = I(x_j = y_j)               для номинального признака,
S_Z(x,y) = Σ[j] w_j · s_j(x,y) / Σ[j] w_j,
d_Z(x,y) = 1 − S_Z(x,y).
```

`ε_j` задаётся по смыслу признака. Например, возраст 30 и 32 считается совпадающим при допуске 3. Пороговая мера использована и описана в [статье Е. В. Смирновой, формулы 5–6](https://cyberleninka.ru/article/n/metodika-opredeleniya-tipa-struktury-tovarnogo-rynka.pdf); в печатной формуле используется строгая граница, поэтому правило равенства порогу нужно оговаривать отдельно.

Чем больше `S_Z`, тем объекты ближе; чем больше `d_Z`, тем они различнее. При нулевых допусках и равных весах получается сравнение на точное равенство и нормированный Хэмминг. При положительных допусках `d_Z` может нарушать неравенство треугольника: для чисел 0, 0,6 и 1,2 с допуском 1 соседние пары имеют различие 0, а крайняя пара — 1. Поэтому термин «мера близости» точнее, чем безусловное утверждение о математической метрике.

### Жаккар

Для множеств присутствующих элементов:

```text
d_J(A,B) = 1 − |A ∩ B| / |A ∪ B|.
```

Общие отсутствия не повышают сходство. При использовании Жаккара необходимо объяснить, что именно означает присутствие элемента. Применение к транзакциям `признак=значение` и к исходным бинарным симптомам задаёт разные понятия сходства.

## 6. Дескриптивный анализ

Для категориальных данных следует описать объём, число уровней, абсолютные и относительные частоты, моды, пропуски, редкие и постоянные категории. Полезны столбчатые диаграммы, таблицы сопряжённости и связи признаков по V Крамера. Средние произвольных кодов категорий не имеют содержательного смысла.

Для числовых данных дополнительно нужны квантили, медиана, среднее, разброс, асимметрия и распределения. Значения вроде `unknown`, «не применимо» и служебные коды отсутствия события следует разбирать по документации набора, а не автоматически считать одним типом пропуска.

Совпадающие строки могут отражать реальные повторяющиеся профили. Удалять их без обоснования нельзя: это изменяет частоты и структуру данных. Сильно связанные признаки могут многократно усиливать один и тот же аспект сходства; это повод для анализа чувствительности, а не автоматическое требование удалить все связи.

## 7. Оценка качества, значимости признаков и сравнение

### Внутренние показатели

Для объекта `i` силуэт определяется через `a(i)` — среднее расстояние до остальных объектов его группы и `b(i)` — минимальное из средних расстояний до объектов каждой другой группы:

```text
s(i) = [b(i) − a(i)] / max[a(i), b(i)].
```

Положительные значения указывают на более близкую собственную группу; отрицательные — на возможное неудачное назначение. Для одиночных кластеров библиотечное соглашение задаёт силуэт 0. Для всего разбиения усредняют `s(i)`; нужны от двух до `n−1` различных кластеров. [Документация scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.silhouette_score.html).

Оба метода нужно оценивать по одной мере расстояния, одному набору признаков и одним объектам. В большой выборке можно оценивать силуэт на общей воспроизводимой подвыборке, сохраняя обучение на всех строках. В отчёте указывают размер подвыборки и представленные в ней кластеры. Полная матрица расстояний требует квадратичной памяти.

Помимо силуэта нужны число кластеров, их размеры, доля объектов в очень малых группах и устойчивость. Большой силуэт сам по себе не доказывает полезность разбиения. Индексы Калинского — Харабаса и Дэвиса — Болдина в стандартных реализациях опираются на числовые центроиды; их нельзя без обоснования рассчитывать по произвольным кодам категорий.

### Внешние показатели

Если исходные метки классов сохранены отдельно, можно вычислить ARI, AMI/NMI, чистоту и таблицу «класс × кластер». ARI корректирует согласие пар объектов на случайность: 1 соответствует одинаковому разбиению с точностью до перестановки номеров, около 0 — уровню случайного согласия; возможны отрицательные значения. [Определение ARI](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.adjusted_rand_score.html).

Чистота определяется долей объектов, принадлежащих наиболее частому классу каждого кластера. Она растёт при дроблении и равна 1 для разбиения на отдельные объекты. Поэтому её рассматривают вместе с числом групп и другими показателями. Номера кластеров не равны номерам классов; обычную accuracy без согласования меток использовать нельзя.

Подбор `k` и `r` по метке класса превращает эксперимент в настройку с внешней информацией. Для основного исследования параметры лучше выбирать по внутренним показателям и устойчивости, затем отдельно оценивать соответствие известным классам.

### Значимость и интерпретация

Для каждого кластера нужны размер и распределения признаков. Характерные категории можно выделить через разность долей или отношение доли категории в кластере к её доле во всей выборке. V Крамера между признаком и номером кластера описывает степень связи с уже полученным разбиением.

Такая связь не является независимым доказательством статистической значимости: эти же признаки участвовали в формировании кластеров. Дополнительная проверка — исключить признак, повторить обучение и сравнить разбиения по ARI. Если используется вспомогательный классификатор номера кластера, его важности описывают воспроизводимость разбиения, а не причинное влияние признаков.

Для сравнения CLOPE и второго метода полезны общий силуэт, размеры групп, устойчивость между запусками, ARI между решениями и содержательные профили. Стоимости `Profit` и `J` принадлежат разным алгоритмам и напрямую не сравниваются. Сопоставление при одинаковом числе кластеров можно добавить как отдельный эксперимент.

## 8. Разбор демопримера Loginom

В [описании сценария](https://examples.loginom.ru/clustering-transactions/index.html) исходную таблицу грибов преобразуют в длинный формат: добавляют ID, сворачивают признаки в пары «название — значение» и объединяют их в элемент транзакции. В узле назначают поля транзакции и элемента, затем изучают размеры и частоты в полученных группах. Для интерпретации результаты соединяют с исходной таблицей по ID.

Деталь для собственного эксперимента: опубликованный пример показывает включение поля класса в свёртку и формирование элемента `Класс — ядовитый`. Для независимой оценки лабораторной целевую метку следует исключить до преобразования признаков в транзакции. Иначе класс участвует в построении групп, а последующая оценка их чистоты по этому классу содержит утечку.

Вход узла — два дискретных поля: идентификатор транзакции и её элемент. На выходе доступны назначения кластеров и характеристики `N`, `W`, `S`. В документации коэффициент отталкивания по умолчанию равен 2,6; предусмотрены ограничения числа кластеров и проходов. [Документация узла](https://help.loginom.ru/userguide/processors/datamining/transaction-clustering.html).

Интерактивный демостенд открывается как веб-приложение без доступного текстового содержимого. Описанный выше разбор относится к опубликованному сценарию, а не к самостоятельно выполненному запуску Loginom.

## 9. Уточнения к презентациям

1. «Кластеризация.pdf», страницы 11–13: нормальность распределений и отсутствие любых корреляций не являются общими обязательными условиями всех методов кластеризации. Для CLOPE и k-modes проверка нормальности категориальных кодов не нужна.
2. Та же презентация, страница 26: для произвольных категорий расстояние Хэмминга считает несовпадения. Манхэттенское расстояние суммирует абсолютные разности; совпадение этих определений относится к бинарным векторам.
3. «Кластеризация.Категор.Смешанн.Данных.pdf», страница 21: увеличение `r` усиливает требование к сходству внутри группы и обычно дробит разбиение. Формулировку о снижении сходства нельзя трактовать как требование собирать более разные транзакции вместе.
4. «Кластеризация.Иерарх.Метод.pdf», страница 12: для complete linkage выбирается максимальное расстояние, несмотря на слово «наименьшее» на слайде.
5. «Кластеризация.Метрики.Значимость.Признак.pdf», страница 9: индекс Жаккара для пар равен `TP / (TP + FP + FN)` и исключает `TN`. Обозначение `FN` у исключённых пар — опечатка.
6. Та же презентация, страница 14: чистота 1 не доказывает оптимальность кластеризации без учёта дробления на малые группы.
